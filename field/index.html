FROM DIAGRAM TO DEFENSIBLE MACHINE EXPERIMENT

Two computers.
One tiny job.

An independent requester asks another independent computer to hash a short public string. The receiving computer can ignore, refuse, hold, approve, stop, or return a signed and independently verified result.

THIS PAGE DOES NOT START OR ACCESS ANY HARDWARE. The native two-process GHoT software is testable; a real two-machine trial still needs two explicitly consenting owners, Linux computers, independent key verification and a private authorized connection. THE OPERATOR'S SEQUENCE

Prepare the crossing.
Leave permission local.

Choose the machines

Two owned or expressly authorized Linux systems. Both operators know what the experiment will do. No campus or ministry resources are assumed available.

Install the pinned native experimental software

The operator independently obtains the inspected GHoT source and selects the exact RADIO HOUSE 004 commit.

git clone https://github.com/the-static-collective/GHoT.git
cd GHoT
git fetch origin experiment/radio-house-004-clicky-lan
git checkout --detach 91efe8441a567944dff27e1206d4967876485dbd
python3 -m unittest discover -s tests -p 'test_radio_house_004.py' -v

Exchange verified public identities

Requester and worker each generate their own key, share only the public part and verify fingerprints by an independent trusted route. No private keys enter MSyoU.

Agree on a narrow network path

Use an administrator-reviewed SSH forwarding-only account. Never publicly expose the worker's owner dashboard. The native worker binds only to loopback interfaces.

Offer one tiny public task

Requester sends an exact signed GHoT proposal. The worker inbox records PENDING; no computation begins on receipt.

Worker owner decides

On its own computer, the worker operator checks media status and power conditions, then explicitly approves and advances. Missing evidence means HOLD.

Inspect the result

Requester independently verifies the signed result and hash. Record failures, refusals, withdrawal and real sensor conditions. Do not confuse test completion with energy saved or institutional approval.
